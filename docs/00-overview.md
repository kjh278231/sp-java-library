## 1. 목표

OR-Library Set Partitioning 인스턴스 55개(nw01–43, aa01–06, kl01–02, us01–04)에서
OR-Tools(CP-SAT, SCIP)보다 **해 품질과 최적성 증명 시간 모두** 우위인 순수 Java 솔버를 만든다.

- 외부 런타임 의존성 없음. LP 엔진을 포함해 전부 자체 구현(01 §11).
- "우위"의 판정 기준은 01 §9에 사전 고정하고 벤치 이후 바꾸지 않는다.
- 틀린 하한으로 "이기는" 일이 없도록 검증 장치를 첫 마일스톤부터 갖춘다(01 §8, 03 §1).

## 2. 문제 정의

```
min  Σ_j c_j x_j
s.t. Σ_j a_ij x_j = 1   ∀ i ∈ R      (각 행을 정확히 한 번 커버)
     x_j ∈ {0,1}
```

- `c_j`는 양의 정수(OR-Library 기준). 내부적으로 `long`. 모든 비용의 최대공약수 `g`를 하한 올림에 쓴다(02 §4).
- 규모: 행 `m` = 17~823, 열 `n` = 약 200~1,053,137. **m이 작고 n이 매우 크다**는 비대칭이 자료구조와 LP 전략 전체를 결정한다.
- `x_j ≤ 1`은 행 제약이 함의하지만 LP에는 **명시적 상한으로 유지**한다. 열 추가·분기·고정을 전부 bound 변경으로 처리하기 위한 전제다(02 §5).
- 파일 포맷: 첫 줄 `rows cols`, 이후 열마다 `cost k r1 ... rk`(행 번호 1-based).

## 3. 왜 범용 솔버를 이길 수 있는가

| 구조적 사실 | 활용 | 상세 |
|---|---|---|
| 각 행 제약이 곧 **클리크**(같은 행을 공유하는 열은 상호 배타) | 충돌 검사 = 비트마스크 AND 한 번. m ≤ 1024 → 열당 `long[16]` | 01 §3 |
| LP 완화가 타이트하고 비용이 정수 | 정확한 LP 쌍대 + **감소비용 고정**으로 열 대부분 제거. `LB = g·ceil(z/g)` | 02 §4 |
| n ≫ m | **Sifting**: 작은 core LP + 전체 열 O(nnz) pricing. m ≤ 823이라 기저 연산이 싸다 | 02 §5.4 |
| **Ryan–Foster** 분기가 변수 분기보다 균형적 | 트리 깊이 감소. 범용 MIP는 이 분기를 쓰지 않는다 | 02 §7.1 |
| 충돌 그래프에는 **어느 행에도 담기지 않는 클리크**가 있다 | clique cut. Hoffman–Padberg branch-and-cut의 주력 cut | 02 §8 |
| CP-SAT의 강점은 병렬 LNS | SPP 전용 **정확 재해결 LNS** 워커 다수 + 공유 incumbent | 02 §6, 01 §6 |

이 설계의 단일 핵심 부품은 **bounded dual simplex 하나**다. root 시작, sifting의 열 추가, 분기, 고정, cut 추가가
전부 "bound 변경" 또는 "행 추가"로 표현되어 dual simplex의 warm-start 안에서 처리된다(02 §5.3). primal simplex는 구현하지 않는다.

## 5. 핵심 설계 결정

| # | 결정 | 근거 | 이전 판 대비 | 상세 |
|---|---|---|---|---|
| 1 | LP 엔진은 bounded dual simplex 하나 | 시작 기저·열 추가·분기·고정·cut이 모두 bound 변경 또는 행 추가로 표현된다 | 신규 원칙 | 02 §5.3 |
| 2 | Sifting으로 UB에 의존하지 않는 정확 LP 쌍대 | Volume 하한과 초기 UB가 느슨하면 core가 수만 열이 된다. sifting은 core 크기 가정이 없다 | "core는 수천 열" 가정 폐기 | 02 §5.4 |
| 3 | Ryan–Foster를 `ub := 0` bound 변경으로 | 분기 대상은 기저 열이라 물리 삭제 시 기저가 무효 | "열 삭제" 폐기 | 02 §7.1 |
| 4 | 희소 LU 기본, dense LU는 m ≤ 150 한정 | m=823 dense LU는 회당 0.1~0.3 s. best-bound 점프마다 재인수분해하면 수 분 | "dense LU 허용" 축소 | 02 §5.6 |
| 5 | Presolve에 행 지배 추가 | `cols(r) ⊆ cols(s)`면 `cols(s)∖cols(r)` 삭제. 가장 큰 축소를 내는 규칙 | "동일 행 병합"은 특수 경우 | 02 §2 |
| 6 | Clique cut 1순위, 조건부 필수 | 행에 담기지 않는 클리크가 존재하며 LP 점을 자른다. odd-cycle은 크기 4 이상에서 약함 | "clique cut 무의미" 철회 | 02 §8 |
| 7 | 감소비용 고정에 정수 강화와 x_j=1 고정 | `g·ceil((LB+r_j)/g) ≥ UB`. 비용이 정수라 올림이 유효 | 조건 강화 | 02 §4 |
| 8 | 작은 SPP 재해결은 DFS | 부분집합 DP는 2^\|R\| 상태 | "비트마스크 DP" 폐기 | 02 §6 |
| 9 | 검증 장치를 M0~M1에 | 최악 실패는 틀린 하한으로 거짓 증명 | 신규 | 01 §8, 03 §3 |
| 10 | solver 내부 시간을 1차 지표로, 비교 쌍 분리 | Python 모델 생성 시간과 JVM 기동이 결과를 왜곡. SCIP는 단일 스레드 | 지표 정의 추가 | 01 §9 |
| 11 | 정밀 LP를 M2로 앞당김 | 지표 대부분이 nw 계열 root LP 증명 시간에서 나온다 | 순서 변경 | 03 §2 |
| 12 | 외부 런타임 의존성 없음 | 목표 자체가 순수 Java 솔버 | 유지 | 01 §11 |

## 6. 승리 조건 요약

두 비교 쌍 각각에서 다음 셋을 모두 만족한다(01 §9.4).

| 쌍 | Java | 기준선 |
|---|---|---|
| A | 1 스레드(결정론 모드) | OR-Tools SCIP |
| B | 8 스레드 | CP-SAT `num_workers=8` |

1. 알려진 최적값 도달 개수 ≥ 기준선
2. 최적성 증명 개수 ≥ 기준선
3. `t_proof`의 shifted geometric mean(shift 1 s, 시간 초과 PAR-2) < 기준선

시간은 solver 내부 시간이 1차 지표다. 파싱·JVM 기동·Python 모델 생성은 별도 열로 보고한다. 동일 머신, 60 s, 5회 중앙값.

## 7. 용어

| 용어 | 뜻 |
|---|---|
| UB, incumbent | 현재까지 찾은 가능해와 그 비용(상한) |
| LB | 유효 하한. 전역 LB는 큐 노드와 처리 중 노드 LB의 최솟값 |
| `g` | 모든 비용의 최대공약수. `LB = g·ceil(z/g)` |
| 감소비용 `r_j` | `c_j − Σ_{i∈j} u_i`. 쌍대 `u`(또는 LP 쌍대 `y`)에 대한 열 j의 한계비용 |
| 감소비용 고정 | `r_j`와 LB, UB로 `x_j`를 0 또는 1로 고정하는 규칙 |
| core | LP를 실제로 푸는 열의 부분집합 |
| sifting | core LP를 풀고 전체 열을 pricing해 음수 감소비용 열을 추가하는 반복 |
| pricing | 쌍대에 대해 모든 열의 감소비용을 계산하는 O(nnz) 스캔 |
| `x̄` | Volume 알고리즘이 주는 primal 근사해 |
| 분수 support | LP 해에서 `0 < x_j < 1`인 열 집합 |
| Ryan–Foster | 행 쌍 (r,s)를 "함께 덮인다 / 따로 덮인다"로 나누는 분기 |
| plunge | 자식 노드를 즉시 처리해 인수분해를 상속하는 깊이 우선 진행 |
| 점프 | best-bound 노드로 이동. 기저 복원과 재인수분해가 필요 |
| 행 지배 | `cols(r) ⊆ cols(s)`인 행 쌍 관계 |
| ExactRepair | 미커버 행 집합 R을 정확히 덮는 최소 비용 열 조합을 DFS로 찾는 작은 SPP 정확 해법 |
| PAR-2 | 시간 초과를 제한 시간의 2배로 계상하는 규칙 |
| shifted geometric mean | `exp(mean(log(t + s))) − s`, s = 1 s |
