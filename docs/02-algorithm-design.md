# SPP Solver — 알고리즘 설계

개정 3 (2026-09-07). 자료구조(01 §3), 시간 예산(01 §5), 검증 장치(01 §8)는 인프라 문서에 있다. 여기서는 각 단계의 정의, 절차, 정당성을 다룬다.

## 1. 표기와 전제

| 기호 | 뜻 |
|---|---|
| `m`, `n`, `R` | 행 수, 열 수, 행 집합 |
| `rows(j)`, `cols(i)` | 열 j가 덮는 행 집합, 행 i를 덮는 열 집합 |
| `mask_j` | `rows(j)`의 비트마스크 |
| `c_j`, `g` | 열 비용(양의 정수), 모든 비용의 최대공약수 |
| `UB` | incumbent 비용 |
| `u`, `y` | 라그랑지안 쌍대, LP 쌍대 |
| `r_j` | 감소비용 `c_j − Σ_{i∈rows(j)} u_i` |
| `x̄` | Volume의 primal 근사해 |
| `ε` | LP 허용오차 1e-9 |

전제: 비용은 양의 정수. presolve 후 중복 열이 없다. LP에서 `x ∈ [0,1]`은 명시적 상한이다(§5.1).

## 2. Presolve

고정점까지 반복한다. 각 규칙은 "가능해 집합의 최적값 보존"을 불변식으로 하고 규칙별 단위 테스트를 둔다(01 §8).

1. **빈 행**: 덮는 열이 없으면 불가능. 노드 presolve에서는 prune.
2. **중복 열**: 행 집합 해시로 그룹화, 최소 비용 열만 유지. Ryan–Foster의 쌍 존재 정리(§10.5)가 중복 없는 열을 전제하므로 필수.
3. **단일열 행**: 그 열을 1로 고정 → 충돌 열 전부 삭제 → 덮인 행 제거. 반복.
4. **행 지배**: `cols(r) ⊆ cols(s)`이면 `cols(s) \ cols(r)`의 열은 전부 삭제.
   r을 덮는 열은 반드시 s도 덮으므로, 다른 열이 s를 덮으면 s가 이중 커버된다. 두 집합이 같으면 s 제약을 삭제(제약 중복).
   행 bitset의 AND-NOT으로 쌍당 O(n/64), 전체 O(m²·n/64). aa01 약 1e8, us01 약 3e8 워드 연산으로 문제없다.
   Hoffman–Padberg 전처리에서 가장 큰 축소를 내는 규칙이며 노드 경량 presolve에도 넣는다(§7.3).
5. **지배 열(제한적)**: disjoint한 `rows(k) ∪ rows(l) = rows(j)`이고 `c_k + c_l ≤ c_j`면 j 삭제.
   비용이 `Σ_i deg(i)²`에 비례하므로 `deg(i) > D`(기본 5,000)인 행은 건너뛴다. us01에서는 사실상 생략된다.
6. 규칙별 축소량을 로그에 남긴다. 소형 인스턴스에서 presolve 전/후 최적값이 같음을 외부 솔버로 확인한다(01 §8).

## 3. Stage A: Volume algorithm(라그랑지안), 전체 열 대상

- `L(u) = Σ_i u_i + Σ_j min(0, r_j)`. 등호 제약이므로 u의 부호는 자유.
- Volume(Barahona–Anbil): 부분기울기 `g = 1 − A·x_new`, `x̄ ← α·x_new + (1−α)·x̄`. `x̄`는 휴리스틱 초기화와 분기 힌트에 쓴다.
- 반복당 O(nnz), CSC 스트리밍. us01에서 반복당 수십 ms.
- 종료: (a) 반복 상한(기본 500), (b) 50회 연속 무개선, (c) 시간 예산 소진(01 §5), (d) `g·ceil(L/g) ≥ UB`.
- 산출: `LB_L`, `u`, `r_j`, `x̄`.

## 4. 감소비용 고정(Reduced-cost fixing)

임의의 유효 하한 `LB`와 그 쌍대에서 얻은 감소비용 `r_j`, 현재 `UB`에 대해:

- `r_j ≥ 0`이고 `g·ceil((LB + r_j)/g) ≥ UB` → **x_j = 0 고정**. x_j = 1인 어떤 가능해도 비용 ≥ LB + r_j.
- `r_j < 0`이고 `g·ceil((LB − r_j)/g) ≥ UB` → **x_j = 1 고정**. x_j = 0이면 비용 ≥ LB − r_j.

근거는 §10.1. 정수 비용이므로 올림 후 비교가 유효하다.

- 라그랑지안 쌍대(Stage A)와 LP 쌍대(Stage B) 모두에 적용된다. 노드 쌍대로 고정한 것은 그 subtree 안에서만 유효.
- 고정은 UB에 상대적이다. UB가 개선되면 기존 고정은 그대로 유효하고 추가 고정이 가능하다.
- 고정된 열은 "UB보다 좋은 해에 들어갈 수 없는 열"이다. 따라서 LNS(§6-5)도 고정 열을 후보에서 제외해도 된다.

## 5. Stage B: Sifting + bounded dual simplex

### 5.1 LP 형태와 쌍대 가능성

```
min  c·x
s.t. A x + a = 1            a: 행별 인공변수, 경계 [0,0], 비용 0
     Σ_{j∈C} x_j + s = 1    cut 행(M5), s ≥ 0
     0 ≤ x ≤ 1
```

쌍대 가능성 조건: 비기저 변수가 하한에 있으면 `r_j ≥ 0`, 상한에 있으면 `r_j ≤ 0`, 고정 변수는 무관.

### 5.2 시작 기저

인공변수 전부. 쌍대 `y = 0`이므로 `r_j = c_j ≥ 0`, 모든 x_j는 하한 0에서 쌍대 가능.
인공변수는 값 1로 상한 0을 위반하므로 dual simplex가 밀어낸다. 별도의 phase 1이나 primal simplex가 필요 없다.
종료 시 인공변수가 기저에 0이 아닌 값으로 남으면 불가능.

### 5.3 모든 사건을 bound 변경 또는 행 추가로 표현

| 사건 | 처리 | 쌍대 가능성 |
|---|---|---|
| sifting 열 추가(`r_j < 0`) | 비기저, **상한 1에 배치** | 유지(상한에서 r_j ≤ 0). primal 위반 → pivot |
| Ryan–Foster 분기, x_j=0 고정 | `ub := 0` | 유지. 기저 열이면 primal 위반 → pivot |
| x_j=1 고정 | `lb := 1` | 유지 |
| cut 추가 | 새 행, slack을 기저에 | 유지(slack 비용 0) |
| 노드 점프 | 경로의 bound 델타 재적용 + 저장 기저 복원 + 재인수분해 | 저장 기저는 해당 노드에서 최적이므로 쌍대 가능 |

열을 물리적으로 삭제하거나 삽입하지 않는다. 분기 대상 열은 분수값을 가진 **기저 열**이고, 기저 열을 지우면 기저가 무효가 된다.

### 5.4 Sifting 루프

UB에 의존하지 않고 정확한 LP 쌍대를 얻는 것이 목적이다.

1. 초기 core: Volume 감소비용 기준 각 행의 상위 k열(기본 k=10) ∪ `r_j ≤ τ`인 열 ∪ `x̄` support ∪ incumbent 열. 상한 20m 열.
2. core LP를 dual simplex로 풀어 쌍대 `y`를 얻는다.
3. 전체 열 pricing: `r_j = c_j − y·a_j`, CSC 순회 O(nnz).
4. `r_j < −ε_price`인 열을 가장 음수부터 최대 2m개 추가(상한 1에 배치) → 2로.
5. 추가할 열이 없으면 종료. `z_LP`는 **전체 문제**의 LP 최적값, `y`는 정확한 쌍대(§10.3). `LB = g·ceil((z_LP−ε)/g)`.
6. 정확 감소비용 고정(§4) → 고정이 있으면 LP 재해결 → 다시 고정. 최대 3회.

수렴 전에 시간 예산이 끝나면 현재 `y`로 `L(y) = Σ y_i + Σ_j min(0, r_j)`를 계산해 하한으로 쓴다. 이 값은 임의의 y에 대해 유효하다(§10.2).
core 크기가 "수천 열"이 될 것이라는 가정에 설계가 의존하지 않는다.

### 5.5 Dual simplex 구현 범위

- bounded, revised form. 쌍대 가격은 Dantzig로 시작, M6에서 dual steepest edge.
- 비율 검사: Harris 2-pass. 모든 변수가 [0,1] boxed이므로 bound flipping ratio test가 효과적이다(M6).
- 허용오차: primal/dual 1e-9, pivot 1e-7. 퇴화 대응: 비용 perturbation 후 제거·재최적화.
- 불가능 판정: 비율 검사에 진입 후보가 없음 → 쌍대 무한 → primal 불가능 → 노드 prune.
- 시간 제한 체크: 100 pivot마다(01 §5).

### 5.6 LU 인수분해

| 방식 | 적용 범위 | 근거 |
|---|---|---|
| Markowitz 희소 LU + Forrest–Tomlin 업데이트 | 기본. 갱신 50~100회 또는 fill 초과 시 재인수분해 | SPP 기저 열은 nnz가 수 개. 재인수분해가 ms 단위 |
| Dense LU | m ≤ 150인 인스턴스 | 단순하고 이 크기에서는 더 빠름 |

m = 823의 dense LU는 회당 약 2×10⁸ flop, Java에서 0.1~0.3 s다. best-bound 점프마다 재인수분해하면 노드 수천 개에서 수 분이 새므로
소형 인스턴스 이외에서는 금지한다.

## 6. Primal 휴리스틱

1. **GreedyRC**: 감소비용 오름차순으로 충돌 없는 열 선택. 미커버 행이 남으면 실패 → 2로.
2. **LagrangianRepair**: `x̄` 상위 열을 선택한 뒤 미커버 행을 "그 행들만 정확히 덮는 열" 탐색으로 복구. 실패 시 충돌 열 제거 후 재시도(횟수 제한).
3. **LpDive**: LP 해에서 `x_j` 최대 열에 `lb := 1` → dual simplex 재최적화 → 반복. 깊이 제한, 백트랙 1회, 불가능이면 중단.
4. **ExactRepair**(작은 SPP 정확 재해결): 입력은 미커버 행 집합 R(|R| ≲ 40~60). 후보 `C_R = { j : mask_j ⊆ R, 미고정 }`을 마스크 필터로 뽑는다.
   - 탐색: 가장 낮은 미커버 행 r을 고르고, r을 덮으며 현재 covered와 충돌하지 않는 후보 열로 분기하는 **DFS**.
   - 가지치기: `현재 비용 + Σ_{i∈R 미커버} u_i + Σ_{j∈C_R 미사용} min(0, r_j) ≥ best`. 후보는 감소비용 순으로 정렬.
   - 상태 수 상한(기본 1e5)으로 시간을 보장한다.
   - 부분집합 DP는 상태가 2^|R|이라 쓰지 않는다.
5. **LNS**: incumbent에서 k열 제거 → R = 제거 열들의 행 합집합 → ExactRepair → 개선 시 incumbent 갱신(01 §6).
   이웃 전략은 워커별로 다르게 배정한다.
   - 랜덤 k열
   - 인접 행 블록: 임의 행 s와, s를 덮는 incumbent 열들이 덮는 행
   - LP 분수 support 주변: 분수값 열과 겹치는 incumbent 열
   - 고비용 열 주변
   - `x̄` 대비 편차가 큰 열
   - k는 성공률 기반으로 적응. 시드는 워커별 고정. 고정 열은 후보에서 제외(§4).

## 7. Branch & Bound

### 7.1 분기: Ryan–Foster를 bound 변경으로

- LP 분수해에서 행 쌍 (r, s)를 고른다. `f(r,s) = Σ_{j∋r,s} x_j`가 0.5에 가장 가까운 쌍.
  분수해가 존재하고 중복 열이 없으면 `0 < f < 1`인 쌍이 항상 존재한다(§10.5). 후보는 분수 support(수십~수백 열)의 행 쌍만 훑으면 된다.
- 좌 노드: r, s 중 **하나만** 덮는 열에 `ub := 0`. 우 노드: r, s를 **둘 다** 덮는 열에 `ub := 0`.
- 보조 규칙: `max x_j ≥ 0.9`인 열이 있으면 plunge 중에는 `lb := 1` 변수 분기도 허용한다. x_j = 1은 충돌 열 전부를 제거하므로 강력하다.

### 7.2 노드 순서

- 기본은 **plunge**(dive): 자식 중 하한 추정이 좋은 쪽을 즉시 처리. 부모 인수분해를 Forrest–Tomlin 업데이트로 상속.
- prune되면 **best-bound** 노드로 점프. 점프 시 재인수분해(희소 LU, ms). 점프 횟수를 로그에 남긴다.
- 전역 LB = min(큐의 노드 LB, 처리 중 노드 LB). 증명 = 큐 비움 or 전역 `LB ≥ UB`.
- 노드는 부모 대비 bound 델타와 최종 기저(기저 열 인덱스 m개 + 비기저 상태 비트)만 저장한다.

### 7.3 노드 처리 순서

1. bound 델타 적용. 점프면 경로를 재구성하고 기저를 복원해 재인수분해.
2. dual simplex → z. 불가능 → prune. `LB_node = g·ceil((z−ε)/g)`. `LB_node ≥ UB` → prune.
3. 노드 쌍대로 감소비용 고정(subtree 한정). 고정은 그 노드 LP의 쌍대가 있어야 하므로 LP 뒤에 온다.
4. 경량 presolve: 단일열 행 → `lb := 1`과 충돌 열 `ub := 0`, 행 지배, 열 없는 행 → prune.
5. 3~4에서 변화가 있으면 2로(최대 2회 반복).
6. 정수해면 Verifier 통과 후 incumbent 갱신 → prune.
7. (M5) root와 깊이 ≤ d에서 cut 분리 라운드(§8).
8. 분기(§7.1).

## 8. Cuts (M5)

행 클리크는 제약에 있지만, 충돌 그래프에는 **어느 한 행에도 담기지 않는 클리크**가 존재한다.

```
A={1,2,3}  B={1,4,5}  C={2,4,6}  D={3,5,6}
네 열은 쌍마다 행을 하나 공유하지만 공통 행은 없다.
LP 해 x_A = x_B = x_C = x_D = 1/2 → 모든 행의 합이 1 (LP 가능해)
x_A + x_B + x_C + x_D ≤ 1 은 유효한 clique 부등식이고 이 점을 잘라낸다.
크기 3 odd-cycle 부등식(x_A+x_B+x_C ≤ 1)도 자르지만 clique 부등식이 지배한다.
```

- **Clique 분리(1순위)**: 분수 support 열(보통 수십~수백)을 정점, 행 공유를 간선으로 하는 그래프에서 `x_j` 가중 greedy로 극대 클리크를 키운다.
  `Σ x_j > 1 + ε`이면 위반. 한 행에 통째로 담기는 클리크는 이미 제약이므로 건너뛴다.
- **Odd-cycle 분리(2순위)**: 같은 support 그래프에서 이분 복제 그래프 최단경로로 분리. `Σ_{j∈C} x_j ≤ (|C|−1)/2`.
- cut은 행 추가이므로 dual simplex warm-start 안에서 처리된다(§5.3). CutPool에 보관, 비활성 cut은 재인수분해 시점에 제거.
- 적용 범위: root 최대 R라운드, 이후 깊이 ≤ d 노드에서만.
- **트리거**: M3에서 aa 계열이 노드 수 폭발로 증명에 실패하면 즉시 착수한다(03 §5). SCIP는 clique/odd-cycle cut을 기본 탑재하므로
  cut 없이 SCIP와 같은 증명 개수를 내려면 근거가 필요하다.

## 9. 병렬 탐색의 알고리즘적 측면

실행 틀(스레드 구성, 공유 객체, 결정론 모드)은 01 §6. 여기서는 알고리즘에 영향을 주는 규칙만 적는다.

- LNS 워커의 UB 갱신은 B&B의 다음 노드에서 감소비용 고정(§4)에 반영된다. 새 고정은 이미 큐에 있는 노드에도 그 노드를 처리할 때 적용된다.
- LNS는 고정 열을 후보에서 제외한다. 고정 열은 UB보다 좋은 해에 들어갈 수 없으므로 개선 탐색에서 잃는 것이 없다.
- 병렬 B&B에서 전역 LB는 큐 노드와 처리 중 노드 LB의 최솟값이다. 처리 중 노드를 빼면 LB가 과대평가되어 거짓 증명이 난다.
- 결정론 모드에서는 LNS 이동을 B&B 노드 사이에 고정 비율로 삽입한다. 병렬 모드와 결과가 다를 수 있으나 재현 가능하다.

## 10. 정당성 논거

### 10.1 감소비용 고정

임의의 가능해 x에 대해 `Σ_i u_i (Σ_j a_ij x_j) = Σ_i u_i`이므로 `c·x = Σ_i u_i + Σ_j r_j x_j`.
- `x_j = 1`, `r_j ≥ 0`이면 `c·x ≥ Σ_i u_i + Σ_{k: r_k<0} r_k + r_j = L(u) + r_j`.
- `x_j = 0`, `r_j < 0`이면 `c·x ≥ Σ_i u_i + Σ_{k≠j, r_k<0} r_k = L(u) − r_j`.
비용이 정수이고 g의 배수이므로 `c·x ≥ g·ceil(v/g)`로 올릴 수 있다. LP 쌍대 y에 대해서도 같은 식이 성립한다.

### 10.2 임의의 y에 대한 `L(y)`의 유효성

`L(y) = min_{x∈[0,1]^n} { c·x + y·(1 − A x) }`는 라그랑지안 함수이며, 모든 가능해 x에 대해 `1 − A x = 0`이므로 `L(y) ≤ c·x`. y의 선택과 무관하다.

### 10.3 Sifting 종료 시 `z_LP`가 전체 LP 최적값

core LP의 최적 기저와 쌍대 y에 대해 core 밖 모든 열이 `r_j ≥ −ε_price`이면, 그 열들을 하한 0의 비기저로 둔 기저가 전체 LP에서 쌍대 가능하고 primal 가능하다. 따라서 최적이다.

### 10.4 고정 후 LP 하한의 유효성

감소비용 고정으로 제외된 열은 "UB보다 좋은 어떤 가능해에도 들어가지 않는다"가 증명된 열이다. 따라서 남은 열만의 LP 하한은 UB보다 좋은 해 전체에 대한 유효 하한이고, 이것이 UB 이상이면 UB가 최적이다. 고정에 쓴 UB보다 나중 UB가 작아져도 논거는 유지된다.

### 10.5 Ryan–Foster 쌍의 존재

LP 해에 분수 열이 있고 중복 열이 없으면, 어떤 분수 열 j와 그 열의 행 r에 대해 r을 덮는 다른 분수 열 j'이 존재하고(행 합이 1), j와 j'은 행 집합이 다르므로 한쪽에만 속한 행 s가 있다. 그러면 `0 < f(r,s) < 1`이다.

### 10.6 Presolve 규칙의 불변식

- 중복 열: 같은 행 집합 중 비용이 큰 열은 어떤 최적해에서도 비용이 작은 열로 교체 가능.
- 단일열 행: 그 열 없이는 그 행을 덮을 수 없으므로 모든 가능해에 포함된다.
- 행 지배: §2-4의 논거. 삭제 열은 어떤 가능해에도 들어갈 수 없다.
- 지배 열(쌍): j를 쓰는 가능해에서 j를 {k, l}로 바꾸면 덮는 행 집합이 같아 가능해가 유지되고 비용이 늘지 않는다.

### 10.7 노드 고정의 범위

노드 LP 쌍대로 얻은 감소비용은 그 노드의 bound 집합 아래에서만 유효하므로, 고정은 자식 노드에만 상속하고 형제나 조상에는 적용하지 않는다.
